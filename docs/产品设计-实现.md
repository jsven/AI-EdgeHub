# AI-EdgeHub 边缘智能中台系统
## 需求与技术规范文档 (v1.0)
---

## 1. 项目概述
### 1.1 项目目标
构建一个通用的 AI 视觉中间件平台，向下兼容传统 RTSP/ONVIF 摄像头及工业相机，向上支持加载多种深度学习模型（如 PaddlePaddle, ONNX），实现视频流实时抓取、AI 推理分析及结果下发，赋予传统安防设备“大脑”。

### 1.2 核心价值
+ **利旧升级：** 无需更换摄像头，通过增加边缘主机实现 AI 功能。
+ **降本增效：** 针对 Intel CPU 进行极致优化，无需昂贵显卡。
+ **极速部署：** 模块化设计，新场景部署周期从月级缩短至天级。

---

## 2. 业务需求说明 (PRD)
### 2.1 功能需求模块
| 模块 | 功能项 | 详细描述 |
| :--- | :--- | :--- |
| **视频流管理** | 多源接入 | 支持 RTSP、RTMP、ONVIF、USB、Local File 接入。 |
|  | 视频分发 | 支持将 AI 渲染后的带框视频流反向推送到 NVR 或大屏。 |
| **模型管理** | 灵活部署 | 支持上传 `.onnx`、`.xml (OpenVINO)`、`.pdmodel` 格式模型。 |
|  | 参数配置 | 可在线配置模型的输入尺寸、归一化参数（Mean/Std）。 |
| **AI 推理引擎** | ROI 配置 | 支持在画面中绘制多个检测区域（多边形、矩形）。 |
|  | 逻辑规则 | 支持置信度阈值、连续帧触发判定、检测频率设定。 |
| **结果下发** | 工业联动 | 支持通过 Modbus TCP、MQTT 或 TCP 协议对接 PLC。 |
|  | 告警推送 | 支持 Webhook 推送、HTTP API、邮件及声光报警器驱动。 |
| **管理后台** | 可视化面板 | 实时查看 CPU 负载、各通道推理延迟及历史告警统计。 |


### 2.2 非功能需求
+ **实时性：** 对于工业生产线，单次推理及逻辑判定延迟需控制在 100ms 以内。
+ **稳定性：** 支持 7×24 小时运行，具备进程自愈（Watchdog）机制。
+ **易用性：** 全 Web 界面配置，无需修改代码即可上线新场景。

## 3. 技术架构设计 (Tech Spec)
### 3.1 技术栈选型
+ **后端开发：** Python 3.8+ (FastAPI) 或 C++ (高性能需求)。
+ **前端界面：** Vue.js3.0 + Javascript + Element Plus + 多语言支持。
+ **推理引擎：** **Intel OpenVINO**（核心，确保 CPU 流畅运行）、ONNX Runtime。
+ **视频处理：** OpenCV + FFmpeg（硬件加速解码）。
+ **数据存储：** SQLite (配置管理) + Redis (实时状态)。

### 3.2 系统逻辑架构
1. **数据接入层：** 使用 FFmpeg 异步拉取视频流，并将帧存入双端队列缓冲区。
2. **前处理层：** 图像 Resize、颜色空间转换（BGR to RGB）、归一化。
3. **推理层：** 模型调度器根据负载将图像分发给 OpenVINO 推理线程。
4. **后处理层：** 非极大值抑制 (NMS)、ROI 判定、目标跟踪。
5. **动作触发层：** 异步发送结果信号，不阻塞推理线程。

## 4. 关键接口 (API) 设计
### 4.1 模型任务创建接口
+ **Endpoint:** `POST /api/v1/task/create`
+ **Payload:**

```json
{
  "task_name": "轮胎红圈识别",
  "stream_url": "rtsp://admin:123456@192.168.1.100/ch1",
  "model_id": "tire_red_circle_v1",
  "roi_points": [[100, 100], [500, 100], [500, 500], [100, 500]],
  "threshold": 0.85,
  "output_config": {
    "type": "mqtt",
    "topic": "/factory/line1/alarm",
    "payload": "defect_detected"
  }
}
```

### 4.2 工业控制器(IO)输出接口
+ 通过 **Modbus TCP** 写入寄存器地址，控制 PLC 动作。

## 5. 针对性场景方案：轮胎红圈识别
### 5.1 识别逻辑
1. **目标检测：** 使用 PP-PicoDet 算法定位红圈。
2. **二次分类：** 针对红圈局部图像进行形态学分析或二分类模型判定（Solid vs Hollow）。
3. **判定逻辑：** 
    - 若 `label == 'hollow'` 且 `score > 0.9`，计数加 1。
    - 若连续 2 帧识别为空心，触发 GPIO 继电器 1 号口开启（分拣气缸动作）。

### 5.2 硬件建议配置 (无显卡方案)
+ **CPU:** Intel i7-12700 或更高（利用 OpenVINO 对多核的加速）。
+ **内存:** 16GB DDR4。
+ **网络:** 千兆网卡（确保多路高清流不丢包）。

## 6. 部署与维护
1. **容器化部署：** 提供 Docker 镜像，实现一键环境初始化，解决库依赖冲突。
2. **健康监测：** 
    - **监控指标：** 每秒帧率 (FPS)、推理耗时 (Latency)、内存占用。
    - **自动重启：** 监测到进程无响应 10 秒后自动重启分析服务。
3. **远程升级：** 支持通过 Web 后端远程上传新的 `.xml` 模型文件进行算法迭代。
