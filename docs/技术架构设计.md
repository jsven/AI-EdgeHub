## 1. 系统架构概览

### 1.2 技术栈选型

#### 后端技术栈
- **Web框架**: FastAPI 0.104+ (高性能异步框架)
- **Python版本**: Python 3.8+
- **AI推理引擎**: 
  - Intel OpenVINO (主要，CPU优化)
  - ONNX Runtime (备用)
- **视频处理**: 
  - OpenCV 4.8+ (图像处理)
  - FFmpeg (视频流解码)
- **数据库**: 
  - SQLite (配置数据持久化)
  - Redis (实时状态缓存)
- **异步框架**: asyncio + aiohttp
- **任务队列**: Celery (可选，用于异步任务)
- **工业协议**: 
  - pymodbus (Modbus TCP)
  - paho-mqtt (MQTT客户端)

#### 前端技术栈
- **框架**: Vue 3.3+ (Composition API)
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **HTTP客户端**: Axios
- **WebSocket**: Socket.io-client
- **图表库**: ECharts (性能监控图表)
- **视频播放**: Video.js / HLS.js (视频流播放)

## 3. 核心模块设计

### 3.1 视频流管理模块

#### 功能职责
- 支持多种视频源接入（RTSP/RTMP/ONVIF/USB/Local File）
- 视频流解码与帧提取
- 视频流分发（推送到NVR或大屏）
- 视频流健康监测与自动重连

#### 技术实现
```python
# 核心类设计
class VideoStreamManager:
    - 管理多个视频流实例
    - 使用 FFmpeg 异步拉流
    - 使用 OpenCV 进行帧提取
    - 双端队列缓冲帧数据
    - 支持硬件加速解码
```

### 3.2 模型管理模块

#### 功能职责
- 模型文件上传与管理
- 模型格式识别（ONNX/OpenVINO/PaddlePaddle）
- 模型元数据提取（输入尺寸、标签等）
- 模型版本管理

#### 技术实现
```python
# 核心类设计
class ModelManager:
    - 文件存储管理
    - 模型格式解析
    - 模型加载与卸载
    - 模型元数据缓存
```

### 3.3 推理引擎模块

#### 功能职责
- 模型推理执行
- 多线程推理调度

## 4. 数据流设计

### 4.1 视频流处理流程
```
视频源 (RTSP/RTMP)
    ↓
FFmpeg 拉流
    ↓
帧缓冲区 (双端队列)
    ↓
图像预处理 (Resize, Normalize)
    ↓
推理引擎 (OpenVINO/ONNX)
    ↓
后处理 (NMS, ROI判定)
    ↓
规则引擎 (置信度、连续帧判定)
    ↓
触发动作 (Modbus/MQTT/Webhook)
    ↓
结果推送 (WebSocket → 前端)
```

### 4.2 任务执行流程
```
1. 用户创建任务配置
    ↓
2. 系统加载视频流
    ↓
3. 系统加载AI模型
    ↓
4. 启动推理线程
    ↓
5. 循环处理：
   - 提取视频帧
   - 执行AI推理
   - 应用ROI过滤
   - 执行规则判定
   - 触发联动动作
   - 推送结果到前端
```

#### 工业互联

## 6. 数据库设计

### 6.1 SQLite 表结构

#### channels (通道表)
```sql
CREATE TABLE channels (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    url TEXT NOT NULL,
    protocol TEXT NOT NULL,  -- RTSP/RTMP/ONVIF/USB/FILE
    status TEXT DEFAULT 'offline',  -- online/offline/error
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### models (模型表)
```sql
CREATE TABLE models (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    file_path TEXT NOT NULL,
    format TEXT NOT NULL,  -- ONNX/OpenVINO/PaddlePaddle
    input_size TEXT,  -- "640,640"
    labels TEXT,  -- JSON格式标签列表
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### tasks (任务表)
```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    channel_id INTEGER NOT NULL,
    model_id INTEGER NOT NULL,
    roi_config TEXT,  -- JSON格式ROI配置
    rule_config TEXT,  -- JSON格式规则配置
    output_config TEXT,  -- JSON格式输出配置
    status TEXT DEFAULT 'stopped',  -- running/stopped/paused
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (channel_id) REFERENCES channels(id),
    FOREIGN KEY (model_id) REFERENCES models(id)
);
```

#### alerts (告警表)
```sql
CREATE TABLE alerts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id INTEGER NOT NULL,
    alert_type TEXT NOT NULL,
    content TEXT,
    confidence REAL,
    image_path TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (task_id) REFERENCES tasks(id)
);
```

### 6.2 Redis 数据结构

- `channel:{id}:status` - 通道状态
- `task:{id}:stats` - 任务统计信息
- `system:performance` - 系统性能指标
- `alert:recent` - 最近告警列表（List）
