## 1. 部署概述

### 1.1 系统架构

AI-EdgeHub 采用前后端分离架构：

```
┌─────────────────┐
│   前端 (Vue3)   │  ← 用户界面
└────────┬────────┘
         │ HTTP/WebSocket
┌────────▼────────┐
│ 后端 (FastAPI)  │  ← API服务 + 业务逻辑
└────────┬────────┘
         │
┌────────▼────────┐
│   SQLite/Redis  │  ← 数据存储
└─────────────────┘
```

### 1.2 部署方式

系统支持以下部署方式：

1. **开发环境部署**：本地开发测试
2. **单机部署**：前后端部署在同一服务器
3. **分离部署**：前后端部署在不同服务器
4. **Docker部署**：容器化部署（推荐生产环境）

### 1.3 部署流程概览

```
准备环境 → 安装依赖 → 配置系统 → 启动服务 → 验证测试 → 上线运行
```

## 2. 环境要求

### 2.1 硬件要求

#### 最低配置
- **CPU**：Intel i5-8400 或同等性能
- **内存**：8GB RAM
- **存储**：50GB 可用空间（SSD推荐）
- **网络**：千兆网卡

#### 推荐配置（生产环境）
- **CPU**：Intel i7-12700 或更高（支持多路视频流）
- **内存**：16GB RAM 或更高
- **存储**：100GB+ SSD
- **网络**：千兆网卡（支持多路高清视频流）

#### 性能参考
- **单路视频流**：约占用 1-2 CPU核心，500MB-1GB 内存
- **8路视频流**：推荐 8核CPU，16GB内存
- **16路视频流**：推荐 16核CPU，32GB内存

### 2.2 软件要求

#### 操作系统
- **Windows**：Windows 10/11, Windows Server 2016+
- **Linux**：Ubuntu 20.04+, CentOS 7+, Debian 10+
- **MacOS**：macOS 10.15+（仅开发环境）

#### 后端依赖
- **Python**：3.8, 3.9, 3.10, 3.11
- **pip**：最新版本
- **Git**：用于代码管理（可选）

#### 前端依赖
- **Node.js**：16.x, 18.x, 20.x
- **npm**：8.x+ 或 **yarn**：1.22+

#### 可选组件
- **Redis**：5.0+（用于缓存和实时数据，可选）
- **Nginx**：1.18+（用于反向代理，生产环境推荐）
- **Docker**：20.10+（容器化部署）
- **Docker Compose**：1.29+（容器编排）

### 2.3 网络要求

- **端口开放**：
  - 后端API：8000（可配置）
  - 前端：5173（开发）或 80/443（生产）
  - WebSocket：8000（与API同端口）
- **网络带宽**：
  - 每路视频流：2-10Mbps（取决于分辨率）
  - 推荐总带宽：视频流带宽 + 20% 冗余

## 4. 部署方案

### 4.1 方案一：开发环境部署

**适用场景**：本地开发、测试、演示

**特点**：
- 前后端在同一机器
- 使用开发服务器
- 支持热重载
- 配置简单

**架构**：
```
localhost:5173 (前端开发服务器)
    ↓
localhost:8000 (后端API服务器)
```

### 4.2 方案二：单机生产部署

**适用场景**：小规模部署、边缘设备

**特点**：
- 前后端在同一服务器
- 前端构建为静态文件
- 使用Nginx反向代理
- 性能优化

**架构**：
```
Nginx (80/443)
    ├─→ / → 前端静态文件
    └─→ /api → 后端API (8000)
```

### 4.3 方案三：分离部署

**适用场景**：中大规模部署、高可用要求

**特点**：
- 前后端分离部署
- 负载均衡
- 高可用架构
- 扩展性强

**架构**：
```
负载均衡器
    ├─→ 前端服务器1/2 (Nginx)
    └─→ 后端服务器1/2 (FastAPI)
         └─→ 共享存储 (数据库/文件)
```

### 4.4 方案四：Docker容器部署

**适用场景**：生产环境、快速部署、容器化运维

**特点**：
- 容器化部署
- 环境隔离
- 易于扩展
- 一键部署

**架构**：
```
Docker Compose
    ├─→ 前端容器 (Nginx)
    ├─→ 后端容器 (FastAPI)
    └─→ Redis容器 (可选)
```

### 5.2 方案二：单机生产部署

#### 5.2.1 后端部署

**步骤1-4：同开发环境部署**

**步骤5：创建系统服务（Linux）**

创建systemd服务文件 `/etc/systemd/system/ai-edgehub.service`：

```ini
[Unit]
Description=AI-EdgeHub Backend Service
After=network.target

[Service]
Type=simple
User=ai-edgehub
WorkingDirectory=/opt/ai-edgehub/backend
Environment="PATH=/opt/ai-edgehub/backend/venv/bin"
ExecStart=/opt/ai-edgehub/backend/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

**步骤6：启动服务**

```bash
sudo systemctl daemon-reload
sudo systemctl enable ai-edgehub
sudo systemctl start ai-edgehub
sudo systemctl status ai-edgehub
```

**Windows服务**：使用NSSM工具创建Windows服务：

```bash
nssm install AI-EdgeHub-Backend
# 在GUI中配置路径和参数
nssm start AI-EdgeHub-Backend
```

#### 5.2.2 前端构建和部署

**步骤1：构建生产版本**

```bash
cd frontend
npm run build
```

构建产物在 `dist/` 目录。

**步骤2：配置Nginx**

创建Nginx配置文件 `/etc/nginx/sites-available/ai-edgehub`：

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 或IP地址
    
    # 前端静态文件
    root /opt/ai-edgehub/frontend/dist;
    index index.html;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API代理
    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # WebSocket代理
    location /ws {
        proxy_pass http://localhost:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

**步骤3：启用配置**

```bash
sudo ln -s /etc/nginx/sites-available/ai-edgehub /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

**步骤4：配置SSL（可选但推荐）**

使用Let's Encrypt免费SSL证书：

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

### 5.4 方案四：Docker容器部署

#### 5.4.1 创建Dockerfile

**后端Dockerfile** (`backend/Dockerfile`)：

```dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    libgl1-mesa-glx \
    libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖文件
COPY requirements.txt .

# 安装Python依赖
RUN pip install --no-cache-dir -r requirements.txt

# 复制应用代码
COPY . .

# 创建必要的目录
RUN mkdir -p logs uploads/models uploads/videos uploads/alerts

# 暴露端口
EXPOSE 8000

# 启动命令
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

**前端Dockerfile** (`frontend/Dockerfile`)：

```dockerfile
# 构建阶段
FROM node:18-alpine AS builder

WORKDIR /app

COPY package*.json ./
RUN npm ci

COPY . .
RUN npm run build

# 运行阶段
FROM nginx:alpine

COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

**前端Nginx配置** (`frontend/nginx.conf`)：

```nginx
server {
    listen 80;
    server_name _;
    
    root /usr/share/nginx/html;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    location /api {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    location /ws {
        proxy_pass http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

#### 5.4.2 创建Docker Compose配置

**docker-compose.yml**：

```yaml
version: '3.8'

services:
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: ai-edgehub-backend
    ports:
      - "8000:8000"
    volumes:
      - ./backend/uploads:/app/uploads
      - ./backend/logs:/app/logs
      - ./backend/ai_edgehub.db:/app/ai_edgehub.db
    environment:
      - DATABASE_URL=sqlite+aiosqlite:///./ai_edgehub.db
      - REDIS_HOST=redis
      - CORS_ORIGINS=http://localhost,http://localhost:5173
    depends_on:
      - redis
    restart: unless-stopped
    networks:
      - ai-edgehub-network

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: ai-edgehub-frontend
    ports:
      - "80:80"
    depends_on:
      - backend
    restart: unless-stopped
    networks:
      - ai-edgehub-network

  redis:
    image: redis:7-alpine
    container_name: ai-edgehub-redis
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    restart: unless-stopped
    networks:
      - ai-edgehub-network

volumes:
  redis-data:

networks:
  ai-edgehub-network:
    driver: bridge
```

## 10. 故障处理

### 10.1 常见故障

#### 10.1.1 服务无法启动

**症状**：服务启动失败或立即退出

**排查步骤**：
1. 检查日志文件
2. 检查端口占用
3. 检查配置文件
4. 检查依赖安装
5. 检查权限设置

**解决方案**：
```bash
# 检查端口
netstat -tulpn | grep 8000

# 检查日志
tail -f backend/logs/app_*.log

# 检查配置
python -c "from app.config import settings; print(settings.DATABASE_URL)"
```

#### 10.1.2 数据库错误

**症状**：数据库连接失败或查询错误

**排查步骤**：
1. 检查数据库文件权限
2. 检查磁盘空间
3. 检查数据库文件完整性

**解决方案**：
```bash
# 检查权限
ls -l ai_edgehub.db

# 检查磁盘空间
df -h

# 修复数据库（SQLite）
sqlite3 ai_edgehub.db "PRAGMA integrity_check;"
```

#### 10.1.3 视频流连接失败

**症状**：无法连接视频流或频繁断线

**排查步骤**：
1. 检查网络连接
2. 检查视频流地址
3. 检查防火墙规则
4. 检查摄像头状态

**解决方案**：
```bash
# 测试网络
ping camera-ip

# 测试RTSP
ffplay rtsp://...

# 检查防火墙
sudo ufw status
```

### 10.2 性能问题

#### 10.2.1 CPU占用过高

**原因**：
- 任务数过多
- 检测频率过高
- 模型过大

**解决方案**：
- 减少并发任务数
- 降低检测频率
- 使用量化模型
- 升级硬件

#### 10.2.2 内存不足

**原因**：
- 视频流过多
- 模型过大
- 内存泄漏

**解决方案**：
- 减少视频流数量
- 优化模型大小
- 重启服务释放内存
- 增加内存容量

#### 10.3.1 服务崩溃恢复
