为了让这套系统能够真正落地并被工程公司和工厂技工轻松使用，UI/UX 设计必须遵循**“极简配置、深度运行”**的原则。

以下是 **AI-EdgeHub** 系统的功能模块架构、页面清单及详细交互逻辑设计。

---

### 一、 系统功能模块树
1. **资源层（Input）：** 摄像头接入、流媒体管理、录像回放。
2. **核心层（AI Engine）：** 模型文件库、推理引擎（OpenVINO 加速器）、计算负载调度。
3. **配置层（Logic）：** ROI 区域绘制、规则引擎（如果...那么...）、告警策略。
4. **接口层（Output）：** MQTT/API 设置、Modbus TCP/IO 控制器管理、数据大盘。

---

### 二、 核心页面及交互细节
#### 1. 仪表盘（Dashboard - 运行监控页）
+ **页面内容：**
    - **实时性能卡片：** CPU 占用率、内存使用情况、推理平均延迟（ms）。
    - **通道状态矩阵：** 每个摄像头的实时 FPS、运行状态（正常/掉线）。
    - **告警动态流：** 最近 5 条识别出的结果快照（图片+识别内容+置信度）。
+ **交互细节：**
    - 点击“延迟卡片”，弹出历史性能折线图，用于排查什么时间段负载过高。

#### 2. 通道管理（Channel Management - 接入摄像头）
+ **页面内容：** 摄像头列表（名称、IP 地址、协议类型）。
+ **交互细节：**
    - **新增摄像头：** 弹出对话框，输入 RTSP 地址后，窗口下方自动显示**“实时预览”**。如果预览成功，确定键才变为可点击状态（防止录入错误地址）。
    - **批量检测：** 一个按钮检测所有摄像头在线状态，掉线的显示为红色感叹号。

#### 3. 模型中心（Model Hub - AI 仓库）
+ **页面内容：** 模型卡片列表（显示名称、任务类型：检测/分类、导出日期）。
+ **交互细节：**
    - **拖拽上传：** 用户将训练好的 `.xml` 和 `.bin`（OpenVINO）文件直接拖入浏览器。
    - **模型自检：** 上传后系统自动识别模型的输入维度（如 640x640）和标签名称，并在页面上展示出来（如：`0: solid`, `1: hollow`）。

#### 4. 任务配置（Task Config - **最核心的交互页面**）
+ **页面交互逻辑设计（三步走向导）：**
    - **Step 1：选择资源。** 下拉选择“1号摄像头”和“轮胎检测模型”。
    - **Step 2：空间规则绘制（可视化画布）。**
        * 左侧显示摄像头的实时画面。
        * 工具栏提供“多边形”、“矩形”、“绊线”。
        * **交互：** 用户直接在画面上“点位勾画”识别区域（ROI）。画完后，区域变为半透明蓝色蒙版。
    - **Step 3：逻辑与触发设置。**
        * **判定逻辑：** 如下拉菜单选择 `[当识别到]` + `[hollow]` + `[置信度 > 0.9]` + `[持续 2 帧]`。
        * **联动执行：** 下拉选择 `[Modbus TCP 输出]` -> `[寄存器地址: 0001]` -> `[数值: 1]`。
+ **即时验证：** 页面下方提供“调试模式”，开启后，画面实时显示 AI 识别框。用户可以拿轮胎现场测试，看右侧逻辑日志是否变绿，确认配置正确。

#### 5. 工业互联设置（Connectivity - 硬件对接）
+ **页面内容：**
    - **PLC/控制器配置：** IP 地址、端口号、从站 ID。
    - **推送配置：** MQTT Broker 地址、Webhook URL。
+ **交互细节：**
    - **“Ping”测试：** 点击按钮，显示物理网络是否连通。
    - **“模拟触发”：** 一个手动按钮，点击后直接给 PLC 发送一个信号。方便施工人员在不运行 AI 的情况下，先确认气缸、电控系统是否能动。

### 四、 关键交互细节优化 (用户体验)
1. **“所见即所得”的调试：** 
    - 在任务配置页，AI 的框是实时的。用户调整“灵敏度滑块”时，画面上的框会随之变多或变少，帮助用户找到最佳平衡点（FP/FN 平衡）。
2. **一键备份与克隆：** 
    - 工厂通常有多个平行工位。支持“克隆任务”功能，将 1 号线的 ROI 和逻辑配置直接复制给 2 号线，仅需修改 RTSP 地址。
3. **故障静默模式：** 
    - 如果摄像头掉线，系统不仅报警，还会自动尝试重连（Exponential Backoff 策略），并在 UI 上显示“重连中...第 5 次”。
4. **CPU 负载安全阀：** 
    - 如果 CPU 占用超过 90%，系统会自动在页面右上角弹出“负载过高预警”，并建议用户调低某些通道的“推理帧率”（例如从 15fps 降到 5fps）。

### 五、 交付给工程公司的资料包清单
为了方便谈合作，你可以准备一个 U 盘，里面装有：

+ **软件安装包：** 一键安装脚本（Docker-compose 方式）。
+ **示例文档：** 《30分钟快速上手：从拉流到 PLC 联动》。
+ **演示模型：** 一个通用的“安全帽识别”或“红圈识别”Demo 模型。
+ **API 文档：** 方便对方的技术员把数据接入他们自己的大屏。

这套设计将 AI 的复杂性隐藏在了**“拖拽”**和**“画框”**背后，非常适合你提到的那些安防工程商去推广。
